2. Allgemeines zur Datenverarbeitung

Es werden keine personenbezogenen Daten an einen Server des Betreibers übermittelt oder dort gespeichert. Beim Aufruf dieser Website kann es dennoch zu einer Verarbeitung personenbezogener Daten kommen, wenn das Hosting durch einen Drittanbieter erfolgt (z. B. GitHub Pages) oder wenn externe Inhalte (Schriftarten, Icons) nachgeladen werden. Hierzu im Folgenden mehr.

4. Lokale Speicherung im Browser (localStorage)

Diese Website nutzt den sogenannten localStorage Ihres Browsers, um Funktionen bereitzustellen, die Sie aktiv nutzen. Es werden dabei keine Cookies gesetzt und keine Daten an einen Server übertragen – die Speicherung erfolgt ausschließlich lokal auf Ihrem Gerät. Konkret werden folgende Daten gespeichert:

  • Theme-Einstellung (Hell-/Dunkelmodus) – damit Ihre bevorzugte Darstellung beim nächsten Besuch erhalten bleibt.
  • Notenrechner-Daten (Fächer, Noten, Gewichtungen) – damit Ihre Eingaben im Notenrechner nicht verloren gehen.
  • Cookie-Einstellung – Ihre Auswahl im Cookie-Hinweis dieser Seite, damit dieser nicht erneut angezeigt wird.

Sie können die gespeicherten Daten jederzeit selbst löschen, indem Sie den Browser-Cache bzw. die Website-Daten Ihres Browsers für diese Seite leeren. Die Daten verlassen zu keinem Zeitpunkt Ihr Gerät.
